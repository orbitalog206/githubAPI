# 🎯 Objetivo do MVP

Desenvolver a **base inicial do sistema de análise de comércio exterior**, permitindo organizar dados e disponibilizar indicadores iniciais para consulta e comparação.

### **Problema que se resolve**

Dificuldade em acessar, organizar e interpretar dados de comércio exterior de forma rápida e estruturada.

### **Hipóteses que serão validadas**

* Usuários conseguem analisar informações com mais eficiência utilizando dashboards;
* Filtros temporais facilitam a identificação de padrões nos dados;
* Comparações entre municípios e regiões apoiam decisões mais rápidas.

### **Valor entregue ao usuário final**

Disponibilização de uma plataforma capaz de transformar dados brutos em informações visuais e comparáveis.

---

# 📝 Descrição da Solução

Será desenvolvida a **estrutura inicial do sistema**, contemplando processamento de dados e visualização inicial de indicadores.

### **Funcionalidades principais incluídas**

* Coleta de dados de comércio exterior;
* Limpeza e normalização dos dados;
* Dashboard inicial com indicadores gerais;
* Aplicação de filtros temporais;
* Comparação entre municípios e regiões;
* Identificação dos principais produtos comercializados.

### **Limitações conhecidas**

* Dashboard inicial com funcionalidades reduzidas;
* Dados limitados ao conjunto tratado nesta etapa;
* Recursos avançados ainda não implementados.

### **Escopo reduzido**

Disponibilizar apenas os recursos necessários para validar a coleta, tratamento e visualização dos dados.

---

# 👥 Personas / Usuários-Alvo

## **Pessoa 1: Analista de Dados**

Responsável por interpretar informações e identificar padrões nos dados.

**Necessidades:**

* Consultar dados organizados;
* Aplicar filtros para análise;
* Visualizar indicadores rapidamente.

**Problemas atendidos:**

* Grande volume de dados sem padronização.

---

## **Pessoa 2: Gestor Regional**

Responsável por acompanhar desempenho entre municípios e regiões.

**Necessidades:**

* Comparar indicadores;
* Identificar produtos com maior relevância.

**Problemas atendidos:**

* Dificuldade em consolidar informações para tomada de decisão.

# 📊 Critérios de Aceitação

* O sistema deve permitir visualizar indicadores gerais;
* O usuário deve conseguir aplicar filtros temporais;
* O sistema deve permitir comparar municípios e regiões;
* Os dados devem estar tratados e organizados para consulta.

# 📈 Métricas de Validação

* Frequência de utilização dos filtros;
* Feedback sobre clareza das visualizações.
